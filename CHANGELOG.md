# Changelog

## 0.1.0 (2026-11-16)

First public version.

- Guided setup: `doctor` checks Python, ffmpeg, Chrome and keys; `setup` saves keys with hidden input to a private file.
- Film steps: `new`, `validate`, `cost`, `voices`, `sheets`, `images`, `voice`, `talk`, `move`, `build`, `check`, `frames`.
- Character sheets as references for every scene picture (Nano Banana Pro on fal).
- Voices from ElevenLabs with character timings, so captions follow the speech exactly. Cached: a second run costs nothing.
- Lip-synced talk shots with Kling AI Avatar on fal, with a check strip for each clip.
- 1080p build with crossfades, burned-in captions for any script (Devanagari tested), music or a soft drone, -14 LUFS, thumbnail.
- Offline smoke test and CI on Ubuntu and macOS.
